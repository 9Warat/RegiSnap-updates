# RegiSnap updates

Public update feed for **RegiSnap** (manifest only, no source).

- `update.json` — the version manifest the app checks (served via GitHub Pages:
  `https://9warat.github.io/RegiSnap-updates/update.json`).
- Each release's installer is attached as a **Release asset**
  (`RegiSnap-Setup.exe`) — the app downloads it and installs silently.

The RegiSnap source code lives in a separate private repository.
